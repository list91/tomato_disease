# Tomato Disease Detection 🍅🔬

## Описание проекта
Проект для автоматической детекции и классификации болезней листьев томатов с использованием машинного обучения.

## Основные возможности
- Классификация болезней томатов по изображениям листьев
- Использование современных алгоритмов машинного обучения
- Высокая точность определения заболеваний

## Технологический стек
- Python
- PyTorch
- Scikit-learn
- FastAPI
- Gradio

## Установка
```bash
pip install -r requirements.txt
```

## Запуск
```bash
python train_hf.py
python app.py
```
